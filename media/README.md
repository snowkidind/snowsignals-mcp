# SnowSignals / TrendVane — branding media

Public branding assets. This repo is public, so every file here is reachable without GitHub Pages via
`raw.githubusercontent.com`. Use these for directory listings, logos, favicons, and social/hero images.

| Asset | Size | Use | Public URL |
|---|---|---|---|
| `trendvane-icon.png` | 512×512, square | Logo / favicon / directory icon (e.g. APIs.guru, which displays 100×100) | `https://raw.githubusercontent.com/snowkidind/snowsignals-mcp/master/media/trendvane-icon.png` |
| `trendvane-card.png` | 588×798 | The full TrendVane card (wordmark + gauge) — hero / social / docs | `https://raw.githubusercontent.com/snowkidind/snowsignals-mcp/master/media/trendvane-card.png` |

The square icon is a centered crop of the gauge dial from the card (the wordmark is dropped because it
goes illegible at small sizes). If GitHub Pages is later enabled on this repo, the same files also resolve
at `https://snowkidind.github.io/snowsignals-mcp/media/<file>`.
